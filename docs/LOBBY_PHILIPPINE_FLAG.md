# Framed Philippine lobby flag

A flat Philippine flag print hangs on the rear lobby wall behind the player's starting view in Main, in both editions. It replaces the floor-standing flag display. Root: `Framed Philippine flag`, position `(-1.84, 2.15, 9.70)`. The oak frame and cream picture mount match the lobby paintings; the flag image retains its 2:1 proportions with the blue field above the red field.

Flag image downloaded unmodified on 2026-10-26: https://flagcdn.com/w1280/ph.png (8,914 bytes). Provider: [Flagcdn / Flagpedia](https://flagpedia.net/download/api), whose images are based on Wikimedia Commons vector files. Underlying reference: https://commons.wikimedia.org/wiki/File:Flag_of_the_Philippines.svg

The image and print material are in `Assets/_Project/Art/Decor/PhilippineFlag`. Reapply with `ViCSI > Scene Setup > Add Philippine Lobby Flag`. Restyling the lobby recreates the wall print. The former stand, pole and draped flag are removed from the scene when this setup runs.

No APK rebuilt or installed.
