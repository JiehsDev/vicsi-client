## Checks ruled out

The Next footer's measurement branch is guarded by `MeasurementStatusFor`: it returns data only when Measurement is the current step. The initially suspected measurement/photo conflict is not a finding.

The album controller lives on PhotoAlbum while its shown/hidden root is GalleryPanel, so ordinary open/close does not by itself re-run the controller's OnEnable. Duplicate thumbnails on every open are not established by the catch-up loop alone.

## Suggested order and acceptance

1. Update the procedure guidance and checklist first. Verify knife, bloodstain, bottle and body independently; no completion checkmark should imply that an unperformed preparation/storage action has finished.
2. Correct album proportions, then add capture identity, usable inspection and empty/control states. Use an actual scaled photo for the aspect and ruler-readability check.
3. Simplify camera artwork after the workflow messages are consistent.
4. Repair broad UI diagnostics and perform physical Quest readability, reach, stereo and overlapping-panel checks before full UI acceptance.

The existing shared panel style and recent adaptive-dialogue changes provide a base for these updates. No production UI or gameplay files were changed for this review.
