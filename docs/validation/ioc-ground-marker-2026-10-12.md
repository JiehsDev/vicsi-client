# IOC starting ground marker (2026-10-12)

`IOC_Start_Ground_Circle` is a normal root scene object in `CSI_Environment`, using the existing flat cylinder mesh and `IOC_GroundGuidance_Yellow.mat` (translucent yellow with emission). It has no collider and keeps a normal editable Transform. It is no longer parented beneath the IOC, and no runtime code follows or changes its Transform. `SOCOWorkflowInteraction` holds the serialized reference, so moving or scaling the marker in the scene directly changes where the guidance and interaction radius are evaluated.

The existing `SOCOWorkflowInteraction` component now exposes Inspector fields for the marker reference, interaction radius (default 2.5 m), guidance title, multiline guidance message, show-on-approach, and hide-on-briefing. The default text is “Meet the IOC” and “Locate the Incident-on-Scene Commander and receive the initial briefing before beginning the investigation.” On entering the marker radius during the IOC turnover phase, the existing interaction panel becomes available and the existing `NotificationManager` ambient prompt shows the configured title and message. This does not start dialogue automatically. The radius is drawn as a lightweight selected-object Gizmo.

`BeginBriefing()` is the hide/clear trigger: after its existing phase, UI, dialogue-catalog, and distance guards succeed, it clears the configured ambient guidance and hides the marker immediately before starting the existing briefing lines. The existing `SOCOInvestigation` phase callback continues to hide the marker through handoff. A normal scenario scene reload restores the authored marker active state and resets the component's runtime guidance state; the integration test checks both marker and IOC restoration.

Validation: the updated `NarrativeRoleFlowTest` passed all 41 checks. New checks cover root/selectable scene-object setup, editable defaults, custom title/message/radius values, manual marker movement surviving runtime updates, blocked interaction outside the radius, approach prompt and panel availability, prompt dismissal and marker hiding on briefing, hidden state through handoff, and marker/guidance restoration after scene reload. The same run retained the existing IOC conversation, handoff, fingerprint checkpoint/vendor sequence, and case roster checks. Unity Console reported zero `CS` errors after script refresh and test completion.

Changed for this update: `SOCOWorkflowInteraction.cs`, `NotificationUI.cs` (read-only accessor for the current ambient prompt, preserving existing prompt/UI behavior), `NarrativeRoleFlowTest.cs`, and the `CSI_Environment` scene (marker made standalone with its position preserved). No manual Editor wiring is required: the scene reference is assigned. In the Inspector, select `NPC_FirstResponder` and edit its `SOCOWorkflowInteraction` fields; select `IOC_Start_Ground_Circle` to move, rotate, or resize it.
