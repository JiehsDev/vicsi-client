# Photography direction guide — 2026-10-16

Added guidance for the existing overall scene-photography route. Outside the active photo's standing zone, the marker leads to that standing spot. Inside the zone, it switches to the authored camera target. A target outside the inset viewport uses a directional arrow; a target in view uses a location pin whose tip aligns with the target. The pin turns green when the required view is within the existing angle tolerance. Capturing a valid photo advances the guide with the existing route; completing the route removes it.

The guide follows the player's headset camera in a world-space plane 1.6 m away. Viewport placement uses camera projection, with a safe inset from headset edges. Behind-eye targets use yaw/pitch rather than a mirrored projection. Arrow/pin transitions retain a small boundary deadband to reduce flicker. Short labels distinguish “Stand here” from “Face this view” and show distance plus the existing view name. Labels use a dark backing and 24-unit text after rendered inspection exposed poor contrast on bright sky/ground. The arrow and pin use a native UI mesh; no raster assets or external UI package are needed. The Resources-backed overlay shader includes stereo instancing support and keeps the indicator visible against nearby geometry.

The guide automatically attaches to `ScenePhotographyManager` at runtime, requiring no manual scene wiring. It hides before investigation, during other modal UI, when its manager/point is disabled and after completion. Camera-viewfinder ownership permits it. It has no raycast targets, raycaster, colliders or input owner and does not change shutter handling, photo requirements, sequence, procedure gates, scoring or event payloads. It guides overall scene photography only; it does not reveal or choose evidence items for detailed photography.

`PhotoCaptureListener` hides the guide synchronously around the album camera's render and restores the previous state in `finally`, alongside the existing viewfinder suppression. The indicator is never intended to appear in students' album photographs. A focused test checks the guide's actual visibility during the album-camera render, nested suppression and restoration.
